# Mob Loot Bags — Minecraft 26.1.2

Fabric and NeoForge workspace for Minecraft 26.1.2. Shared product docs live in the [repository root README](../README.md).

## Requirements

- Java 25+
- Open this `26.1.2/` folder as the Gradle project root

## Build

```bash
./gradlew build
./gradlew :fabric:runClient
./gradlew :neoforge:runClient
```
