# Promotional reel: "Every kill could be a jackpot"

| File | Use |
| --- | --- |
| `mob_loot_bags_reel.mp4` | The reel: 1080×1920, 30 fps, H.264 High + AAC 48 kHz, 42.0 s, −12.5 LUFS. Upload as-is to TikTok, Instagram Reels and YouTube Shorts. |
| `cover.jpg` | 1080×1920 cover frame (the end card). |

Every shot is real gameplay from the 1.21.1 Fabric build (Mob Loot Bags 2.0.0), rendered frame by frame by the game.
Each kill runs the mod's own drop code; the bags, beams, lightning, reveal toasts, titles, fanfares, loot previews,
machine screens and the Cursed ambush are the mod's own. For each shot the mod's config files were set the way a pack
maker would (a drop chance of 1, the tier the shot shows, a faster Recycler and Hourglass for the time-lapse), so the
take is the same every time. How it was made and how to re-render it: [`tools/reel/README.md`](../../tools/reel/README.md).

**Voice-over:** synthesized offline with [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0), voice
`am_fenrir`, no ElevenLabs. Each line was checked with a speech-to-text pass over the finished mix.

**Music:** an original 120 BPM cue generated by `tools/reel/music.py` (no samples, no licence needed). Every cut sits on
a beat, and the drop lands on the first bag of the tier line.

**Sound effects:** the game's and the mod's own sounds, placed at the frames they played, plus synthesized whooshes.
