# Mob Loot Bags 2.0.2

## Fixes

- **Crash while exploring near generating structures.** When a structure with mobs in
  it generated (for example an illager camp), a mob could be picked to carry a loot
  bag using the world's main random number generator from a world-generation thread,
  and the game crashed with "Accessing LegacyRandomSource from multiple threads".
  Bag carriers spawned during world generation now roll with the spawn's own random,
  as vanilla does.

No gameplay, config or save changes. 2.0.1 worlds load as before.
