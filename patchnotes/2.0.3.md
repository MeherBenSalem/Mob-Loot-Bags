# Mob Loot Bags 2.0.3

## Fixes

- **Machine buttons ignored clicks on Minecraft 26.3.** Minecraft 26.3 numbers mouse
  buttons differently from earlier versions, so the Loot Recycler's Take button and the
  Bag Opener's redstone mode button never saw a left click. Both buttons work again.
  Until you update, sneak-using the Loot Recycler still collects its stored experience.

Only the 26.3 jars change in behaviour; the other versions are rebuilt with the new
version number. No gameplay, config or save changes. 2.0.2 worlds load as before.
