# Mob Loot Bags 2.0.1

## Fixes

- **World-load crash with Apotheosis (All the Mods 9 and other packs).** 2.0.0 rolls
  every bag loot table on server start to build the Shift loot previews. When
  another mod's loot hook threw during one of those rolls (Apotheosis: "Failed to
  locate any affixes for fishing_rod"), the world failed to load. A roll that
  throws is now skipped and logged, and building previews can no longer stop a
  world from loading.
- **Opening a bag with such a mod installed** retries a roll that throws, up to five
  times, instead of crashing the server. If every attempt fails, the error is
  logged and the bag gives nothing.

No gameplay, config or save changes. 2.0.0 worlds load as before.
